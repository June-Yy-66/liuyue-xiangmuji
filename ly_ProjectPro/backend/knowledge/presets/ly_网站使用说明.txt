一、网站概述
本网站是刘悦同学的前端开发课程综合项目，采用原生 HTML/CSS/JavaScript 实现前端（禁止使用第三方框架与 CDN），后端使用 Node.js + Express（端口 8220，RESTful + MVC 风格），数据库为 MySQL（库名 ly_project_db）。所有接口以 /api/ 为前缀，统一返回 JSON 格式 { code, msg, data }，code=0 表示成功。

二、功能页面说明
1. 首页（index.html）：包含姓名刘悦、学号 24002120220、项目名称与类别（自选），页面主体为所有已完成页面的超链接导航，背景使用 canvas 粒子连线动画。
2. 数据库连接页（database.html）：输入用户名与密码连接 MySQL，默认用户名 root，连接成功或失败均有提示，后端接口为 POST /api/database/connect。
3. 科技新闻列表页（news.html）：从 MySQL 表 ly_news 读取新闻，按发布时间倒序展示标题、摘要、来源、时间，接口为 GET /api/news。
4. 图文列表页（photos.html）：从表 ly_photos 读取图文数据，展示标题、描述与图片，接口为 GET /api/photos。
5. 图库图文页（gallery.html）：从表 ly_gallery 读取数据，网格布局展示上图下文卡片，图片加载失败时显示占位色块，接口为 GET /api/gallery，页面适配手机宽度。
6. AI 聊天页（ai_chat.html）：调用硅基流动大模型（Qwen 系列）进行多轮对话，接口为 POST /api/ai/chat，API Key 保存在服务端 .env 文件中。
7. 在线客服页（customer_service.html）：调用七牛在线客服大模型（qiniu/conatus-free），带常见问题快捷提问按钮，接口为 POST /api/customer_service/chat。
8. 知识库问答页（knowledge_base.html）：支持上传 txt、md、pdf、doc、docx、pptx 等格式文件，解析分块入库，基于关键词检索实现 RAG 知识库问答，并提供知识库文件管理（列表、删除）。

三、启动方式
方式一：双击项目根目录的 ly_start_backend.bat，脚本会自动进入 backend 目录执行 npm start。
方式二：命令行进入 backend 目录后执行 node server.js。
启动成功后浏览器访问 http://localhost:8220 即可打开首页。

四、数据库连接信息
数据库地址 127.0.0.1，用户名 root，密码保存在 backend/.env 文件中（变量 DB_PASSWORD），不在代码中硬编码。建表与测试数据 SQL 全部记录在 backend/ly_database.md，可凭该文件在新机器上完整重建数据库。

五、常见问题
问：页面打不开怎么办？
答：请先确认后端服务已启动（黑窗口显示服务已启动），再用 http://localhost:8220 访问，不要直接双击 HTML 文件。

问：图片显示不出来怎么办？
答：图片已全部下载到本地 frontend/images 目录由后端托管，若仍不显示请检查后端服务是否启动。

问：接口返回 404 怎么办？
答：多为服务未启动或端口被旧进程占用，重启后端服务即可。
