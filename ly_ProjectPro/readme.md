## 项目简介

Web 课程作业项目集（项目类别：自选），前端为原生 HTML / CSS / JavaScript，
后端为 Node.js + Express（RESTful + MVC），数据库为 MySQL。

## 目录结构

- `frontend/`：前端静态资源（css / js / fonts / images）
- `backend/`：后端服务，端口 8220，所有接口以 `/api/` 为前缀

## 启动方式

```bash
cd backend
npm i
npm start
```

启动后访问 http://localhost:8220 即可打开首页。
